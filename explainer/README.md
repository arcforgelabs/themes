# Explainer

Public copy of the Arc Forge explainer skill: visual explainer pages, diagrams first, every part opens a definition. Any agent can read it: start with [SKILL.md](SKILL.md).

- [references/chart-lab.html](references/chart-lab.html): every rated chart kind, drawn on one subject (example data).
- [examples/starter.html](examples/starter.html): copy it to start a page.
- [examples/explainer-kit.html](examples/explainer-kit.html): a full page that uses every renderer.

Generated by `scripts/export-public` in the private `arcforgelabs/tools` repo (`components/skills/explainer`, commit `524e64f`). Do not edit this folder by hand: change the source and export again. The `scripts/` folder (bundle and headless check) stays in the source repo.
